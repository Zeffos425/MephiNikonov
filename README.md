## 🛠️ Основные использованные команды

| Команда | Описание |
|---------|----------|
| `git init` | Инициализация нового репозитория |
| `git status` | Отображение статуса рабочего дерева |
| `git add <файл>` | Добавление файла в индекс |
| `git commit -m "..."` | Создание коммита с сообщением |
| `git log` | Просмотр истории коммитов |
| `git diff` | Просмотр изменений в файлах |
| `git checkout -- <файл>` | Отмена изменений в файле |
| `git branch` | Список веток |
| `git branch <имя>` | Создание новой ветки |
| `git checkout <ветка>` | Переключение на ветку |
| `git checkout -b <имя>` | Создание и переключение на ветку |
| `git branch -d <имя>` | Удаление ветки |
| `git merge <ветка>` | Слияние ветки с текущей |
| `git rebase <ветка>` | Ребазирование текущей ветки |
| `git remote add origin <url>` | Добавление удалённого репозитория |
| `git push -u origin master` | Отправка изменений на GitHub |
| `git pull origin master` | Получение и слияние изменений |
| `git fetch origin` | Скачивание данных из удалённого репозитория |
| `git clone <url>` | Клонирование репозитория |
